## About Me

I'm **Raghauv Saravanan**, a dual-degree **Computer Science and Mathematics** student at the
**University of Texas at Austin** (May 2027).

I like problems where the math and the systems both matter — reinforcement learning agents,
compilers and operating systems built from the ground up, and trading algorithms that have to be
right *and* fast. Most of what I build sits somewhere between low-level systems work and applied
machine learning.

- 🏦 Software Engineer Intern at **The Trade Desk**, where I built evaluation tooling for an AI
  troubleshooting chatbot on Kubernetes and data pipelines covering 500K+ ad groups
- 🔐 Before that at **AppSentinels**, fine-tuning DistilBERT for API security classification
- 🤖 Currently Software Engineer, AI Code Evaluation at **Mercor**
- 📈 **59th of 12,500+ teams** worldwide in IMC Prosperity 3 algorithmic trading

## 🚀 What I'm Up To

- Writing a **Pascal compiler** in C — lexer, recursive-descent parser, type checking, and an
  x86 code generator that produces binaries running on real hardware
- Training **deep reinforcement learning agents** for imperfect-information games
- Building **LLM-backed services** with typed schemas, validation and CI that actually catches things
- Going deeper on **distributed systems, ML infrastructure and cloud tooling**
